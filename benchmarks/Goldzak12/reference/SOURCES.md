# LC10 Literature Sources

Only the literature comparisons used by the current manuscript and ESI are
retained. Statistics use identical material sets within each comparison.

- `goldzak2022.csv`: Tables II and III of Goldzak et al., JCP 157,
  174112 (2022), [DOI](https://doi.org/10.1063/5.0119633). Experimental
  lattice constants are the reported zero-point-corrected values. Bulk
  moduli follow Table III; alternate BN/BP/MgO values are retained separately
  in the analysis.
- `zhang2018_selected.csv`: nine overlapping solids and six functionals
  from SI Tables III/V of Zhang et al., NJP 20, 063020 (2018),
  [DOI](https://doi.org/10.1088/1367-2630/aac7f0). AlN is absent from that
  source. The provenance JSON identifies the source PDF and hash.
  Static "Uncorr." values are used; "Corr." includes zero-point motion.
  SCAN was evaluated on PBE orbitals.

Unmatched aggregate scores, atomic cohesive energies and the no-longer-used
xTB, Schimka and Tao-Mo comparison tables are not part of the current release.
